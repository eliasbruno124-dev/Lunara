## App name

Lunara – Private Cycle

## Short description

Private cycle tracking—locally or on your own server.

## Full description

Lunara is a private cycle and period tracker with two clear ways to use it:
standalone and fully local on your Android device, or together through a
self-hosted Lunara server.

Solo mode requires no account or domain. Periods, daily entries, and settings
remain in the encrypted local database. To move to a new device, you can create
a passphrase-encrypted backup file and import it on the new device. Automatic
cloud backup is not included.

In self-hosted couple mode, each person has a separate account and different
permissions. The tracking person decides individually whether to share items
such as the expected period range, actual period dates, estimated cycle phase,
symptoms, or the roughly estimated fertile window. The partner view cannot
edit period data. An installable web app provides browser access to your own
instance, including on iPhone and iPad.

What Lunara offers:

- record period start and end in the calendar, then correct or delete past
  entries
- log flow, pain, mood, energy, sleep quality, temperature, symptoms, and
  optional notes
- work offline and synchronize automatically later in server mode
- estimate the next period as an understandable range instead of a falsely
  precise single date
- show prediction uncertainty and the data behind the estimate
- an optional fertile window that is always clearly labelled as a rough
  estimate
- respectful partner suggestions based only on shared data and personal care
  preferences
- configurable local reminders, with no advertising or analytics SDK built
  into Lunara
- German and English, light and dark themes, and accessible labels

Your instance, your choice: couple mode requires a compatible self-hosted
Lunara server with HTTPS. The instance operator is responsible for operating,
backing up, and updating that server. Authentik sign-in can be enabled, but
Lunara also works with its own account credentials.

Important: cycle phase, expected period range, and fertile window are
statistical estimates based on the data recorded so far. The fertile window
does not confirm ovulation and must not be used as contraception.

Lunara is not a medical device and does not diagnose, treat, cure, or prevent
any medical condition. Consult a healthcare professional for medical advice,
diagnosis, or treatment.
